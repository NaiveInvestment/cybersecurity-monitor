# 사이버보안 모니터

국내외 사이버보안 상장사의 시세, 시가총액, 분기 실적을 한 표로 보고, 해킹 사례와 정책, 기업의 보안 지출을 따라가는 정적 사이트.

- 종목 페이지: 국내 35종목, 해외 36종목. 현재가, 시가총액, 기간 수익률, 최근 분기 매출과 직전 4개 분기 합계, PSR, PER
- 뉴스 페이지: 1차 출처를 확인해 정리한 카드(`data/curated/cards.json`)와 자동 수집 헤드라인

## 구조

| 경로 | 역할 |
|---|---|
| `universe.json` | 종목 정본. 국내는 종목코드, 해외는 네이버 코드(`reuters`), 분야 태그 |
| `public/` | 화면. 빌드 도구 없는 HTML, CSS, ES 모듈 |
| `public/lib/calc.js` | 화면과 수집기가 함께 쓰는 계산(수익률 기준가, TTM, PSR, PER) |
| `src/naver.mjs` | 네이버 금융 수집기(일괄 시세, 일봉, 분기 재무). 키 불필요 |
| `src/news.mjs` | RSS 파싱, 키워드 분류, 중복 제거, 종목명 매칭 |
| `scripts/build-data.mjs` | `data/snapshot.json` 생성 |
| `scripts/fetch-news.mjs` | `data/news.json` 생성(이전 보관분과 병합, 180일 보존) |
| `scripts/build-site.mjs` | `_site/` 조립 |
| `scripts/live-poller.mjs` | 장중 60초 시세를 `live` 브랜치 `live.json`으로 푸시 |
| `src/live-local.mjs`, `scripts/serve.mjs --live` | 로컬 실시간 서버(키움 중계 + 네이버 10초) |
| `scripts/verify-site.mjs` | 조립된 사이트의 채움률, 정합성, 금지 문자 검사 |

## 실행

```
npm run build     # 스냅샷 + 헤드라인 + 사이트 조립 (_site/)
npm run serve     # http://127.0.0.1:8895/
npm test          # 단위 테스트
node scripts/verify-site.mjs _site
```

로컬 빌드는 실시간 폴링을 끈 스냅샷 화면이다. `node scripts/build-site.mjs --live owner/repo`로 켤 수 있다.

## 로컬 실시간

```
npm run live      # http://127.0.0.1:8858/
```

- 국내 35종목은 홍대현 Universe 로컬 서버(`127.0.0.1:8848`)가 중계하는 키움 실시간 체결(KRX)을 받아 쓴다. 키움에 직접 접속하지 않으므로 이 저장소에는 키가 없다
- 해외 종목, 지수, 등락률 기준값, 거래대금은 서버가 네이버를 10초마다 조회한다. Universe 서버가 꺼져 있으면 국내도 네이버 10초 갱신으로 떨어진다
- 화면은 같은 서버의 `live.json`을 2초마다 읽고, 현재가가 바뀐 칸은 한 번 반짝인다. 상태 표시는 `/health`
- 서버는 시작할 때와 3시간마다 스냅샷과 헤드라인을 다시 받아 조립한다
- 바탕화면 바로가기는 `AIWorkspace\bin\launch-cybersecurity-monitor.ps1`을 실행한다. Universe 서버를 먼저 깨우고, 코드가 서버 시작 뒤에 바뀌었으면 서버를 다시 띄운 다음 Chrome으로 연다

## 배포와 갱신

- 공개 주소: https://naiveinvestment.github.io/cybersecurity-monitor/
- PC 로그인 시 `Cybersecurity quote relay` 시작프로그램이 로컬 런처를 실행한다. 키움은 기존 Universe 연결을 재사용한다. 별도 키 사본은 없다.
- Cloudflare 임시 HTTPS 중계는 시세 전용 서버의 `/live.json`만 공개한다. 주소 변경은 `relay` 브랜치에 자동 반영하며, 공개 화면은 2초마다 중계를 읽는다. PC와 키움 연결이 끊기거나 수집이 오래되면 GitHub의 네이버 시세로 자동 전환한다.
- `financials` 브랜치는 PC에서 국내 35종목의 공시 실적과 ConsenDB 예상치만 갱신한다. 공개 배포는 이 파일을 복원한다. 워크북과 API 키, 로컬 설정은 공개하지 않는다.

- `deploy.yml`: main 푸시와 3시간 간격으로 스냅샷, 헤드라인을 다시 받아 GitHub Pages에 배포. 헤드라인 보관분과 직전 스냅샷은 `data` 브랜치에 둔다
- `live-poller.yml`: 아시아장 08:55~15:40 KST, 미국장 22:25~06:10 KST에 60초 간격으로 `live` 브랜치를 갱신. 화면은 75초마다 이를 읽어 시세를 덧씌운다
- 수집이 실패하거나 채움률이 직전의 절반 아래로 떨어지면 빌드가 실패해 직전 배포가 유지된다

## 데이터 기준

- 국내 실적과 밸류는 Universe의 공시와 ConsenDB를 재사용한다. 한 표에서 시세와 수익률을 먼저 보여주고, 오른쪽에 매출, 영업이익, 지배순이익, P/E, P/B, ROE를 모두 이어 붙인다. 각 지표는 2023A부터 2027E까지 연도와 추이를 함께 제공한다. 기본은 3M 평균이며 1M 평균과 3M 최고는 전체 추정치에 함께 적용된다. 2028년은 표시하지 않는다.
- 모든 종목은 페이지 세로 스크롤로 본다. 표 안의 세로 스크롤은 없고, 표 위 좌우 스크롤이 오른쪽 재무 열로 이동한다. 종목명은 좌우 이동 중에도 유지된다. 실적과 밸류 별도 페이지나 지표별 선택은 없다.
- 국내 P/E는 현재 시총/연간 지배순이익, P/B는 현재 시총/연말 지배주주지분, ROE는 지배순이익/전기와 당기 평균 지배주주지분이다. 결측 N/A, 이익이나 자본이 양수가 아닌 배수는 N/M. 해외는 기존 확정 분기와 TTM 기준을 유지한다.
- 상단 비교는 보안35와 공식 SOL, KODEX ETF의 2026-11-12 주식 구성목록을 사용한 17개 자체 바스켓이다. ETF 자체의 수익률이 아니다. 현재 구성을 과거에 적용한 비교이며 배당은 제외한다. 시작일 미상장 종목은 제외하고 포함 수를 표시한다.
- 동일가중은 선택 기간 시작 시 같은 금액을 배분하고 수량을 고정한다. 시총가중은 현재 시총/현재가로 환산한 주식수에 기간 시작 가격을 적용한 근사치다. 공식 과거 시총지수와 구분한다. 데이터와 구성 출처는 그래프의 `구성, 계산 기준`에서 확인한다.

- 출처는 네이버 금융. 수익률은 수정주가 종가 대비, 52주 고점은 종가 기준
- 실적은 확정 분기만 사용. 4개 분기가 이어지지 않으면 TTM을 만들지 않는다. 결측은 `-`로 두고 채우지 않는다
- 해외 영업이익은 EBIT, 순이익은 당기순이익. PER은 직전 4개 분기 순이익 기준이며 0 이하이면 `N/M`
- 원화 환산은 네이버의 원화 환산 시가총액에서 얻은 현재 환율을 쓴다

## 카드 갱신

`data/curated/cards.json`에 카드를 추가하고 main에 푸시한다. 숫자와 날짜는 1차 출처를 직접 열어 확인하고, 계획과 확정과 집행을 `status`로 구분한다. 분모가 다른 숫자는 합치지 않는다.
